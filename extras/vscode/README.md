# Solitude Dawn for VS Code

Warm paper and a single rising-sun amber `#b06f00`. The light companion to
Solitude Dusk: editor `#f4f0e8`, side bars and panels a shade deeper at
`#ebe6dc`, amber cursor, amber top edge on the active tab, and the same quiet
syntax palette darkened for daylight (slate functions, amber types, sage
properties, olive strings).
